## 🌟 Key Portfolio Features

### 🌓 Light & Dark Theme Switcher
- **Default Light Theme**: The portfolio opens in a clean, professional white theme by default.
- **Manual Toggle**: Accessible toggle button in both desktop and mobile navigation allows switching between light and dark modes at any time.
- **Persistence**: Theme preference is stored in `localStorage` and synchronized across all pages (`index.html`, `about.html`, `projects.html`, `skills.html`, `contact.html`).
- **Refined Dark Mode Aesthetics**: Deep slate canvas (`#0b0f19`) with high-contrast typography, frosted glass cards, and project thumbnails with ambient accent glows (sky, violet, emerald, indigo) tailored to eliminate glare.

### 📌 Sticky Frosted Glass Navbar
- **Always Accessible**: Fixed navigation bar remains pinned to the top of the viewport.
- **Dynamic Scroll Blur**: Backdrop filter and frosted glass blur adapt smoothly upon scrolling (`> 15px`) to keep page content legible underneath.
- **Mobile Drawer**: Responsive navigation menu with built-in theme toggle.
